## Supported boundaries

The runtime remains independent of model providers and Studio. The optional workflow facade requires Python 3.9+ and the selected platform prerequisites. Each game configures its own ignored local targets; no host, SSH key, signing team or device is shipped as a default. Apple signing and device authorization remain human-controlled prerequisites. This portable record contains only relative evidence references and omits private host paths, credentials and device identifiers.

Profiles replace explicitly allowed presentation fields; they do not change gameplay geometry implicitly. Cross-revision save reuse is opt-in and conservatively assessed. Scripts, registered gameplay assets and structural changes can require migration. `save-check` is an assessment; an isolated restore validates the actual saved state and migration hook. A mobile scenario ends its native session, and `session launch` explicitly reopens the matching deployed artifact for technical work or human playtesting.

Technical success is distinct from human approval. Historical Windows, Android and iOS measurements remain available in their original records and do not automatically qualify new binaries or behavior.
