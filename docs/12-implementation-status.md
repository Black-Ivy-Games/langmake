# Langmake 0.3 implementation

Authorized scope: the full eight-phase plan accepted on September 18, 2026.
Target: Windows/D3D11, C++20/Luau/JSON, reusable editable game systems.
The human owns creative decisions and gameplay acceptance. Native automated checks
establish technical readiness only. All work remains inside this workspace.

## Completion checklist

- [x] Reliable live publication, compact filtered inspection, retention, player mode
- [x] Shared inputs/cameras and exact-tick graphical captures
- [x] Version-2 source graph, modules, prefabs, dynamic entities and queries
- [x] RmlUi/FreeType HUD, controllers and game cameras
- [x] Native articulated models, cgltf import and ozz animation
- [x] Scene transitions, saves, navigation and reusable gameplay modules
- [x] Shared offline/live audio mixer and effects
- [x] Profiling/debug evidence, reference examples, fresh-agent exercise, release package

## Release gates

Preserve version-1 games and the 0.2 package. Every advertised capability requires
executed evidence. Qualify contention recovery, matching capture/state ticks,
lifecycle cleanup, fresh-process saves, 128-agent navigation, HUD and animation,
audio parity, and portable packaging. Record actual limits and reference hardware.
No interim checkbox or successful build constitutes release readiness.

## Integration ownership

Primary agent: project format, CLI, live bridge, preview/UI integration, build and release.
World agent: runtime/module/state/entity/controller/navigation/save systems.
Asset agent: model compilation, glTF, animation, asset rendering and shaders.
Audio agent: synthesizer, mixer/DSP, live/offline rendering.

Baseline sources were preserved under `.cache/baseline-0.2`; authored games and
the 0.2 portable release are preserved. Integration used `.cache/build-0.3`; the
qualified release is built in `build/` and packaged in `dist/Langmake-0.3/`.
See [release evidence](14-release-evidence.md) for executed checks and limits.

Completed September 18, 2026. The final build passed the graphics-inclusive
